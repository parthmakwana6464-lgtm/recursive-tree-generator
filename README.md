# 🌳 Fractal Tree Art

A lightweight Python generative-art project that renders a recursive fractal tree structure using Python's built-in `turtle` graphics library.

The artwork features a sleek black background paired with a soft purple branch structure generated through recursive programming.

## Requirements

* Python 3 (No external pip installations or dependencies required; `turtle` is part of the standard Python library).

## Run

Make sure your script file (e.g., `tree.py`) is saved in your working directory.

Run the program from your terminal:

```bash
python tree.py

```

On Windows, you can also use:

```bash
py tree.py

```

## Features

* **Zero Dependencies:** Relies entirely on built-in Python modules.
* **Recursive Algorithm:** Uses a clean divide-and-conquer function to branch out symmetrical patterns.
* **Custom Styling:** Features a custom color palette (`#937cbb`) and instant rendering speeds using `speed(0)`.



Enjoy experimenting with fractal geometry and coding! 🌿
